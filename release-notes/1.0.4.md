# SlimeEasy 1.0.4

## Automation safety

- Auto Breaker no longer directly removes registered Slimefun blocks. Stateful Slimefun blocks must go through their normal break lifecycle so addon/core storage stays synchronized.
- Auto Placer no longer converts registered Slimefun item stacks into plain vanilla blocks. Slimefun placement handlers are not bypassed.

This fixes Slimefun Legacy issue #280 where a Territory Core could be removed by Auto Breaker while its territory record remained, and a core item could be placed back as a normal lodestone by Auto Placer.

Normal vanilla block breaking/placing behavior is unchanged.
