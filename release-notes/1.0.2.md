# SlimeEasy Legacy 1.0.2

SlimeEasy Legacy `1.0.2` cleans up the Slimefun Guide layout by placing the addon under one top-level **SlimeEasy** folder.

## Guide organization

- Added a single SlimeEasy parent folder to the Slimefun survival guide.
- Moved Utility Machines, Utility Tools, Storage, Villager, and Territory under that parent folder using Slimefun Legacy's native nested item-group API.
- Child categories remain accessible to Slimefun guide search.
- Existing items, recipes, research IDs, storage data, and feature toggles are unchanged.

## Compatibility

- Slimefun Legacy
- Paper 26.2+
- Java 25 runtime/build target as configured by the project

Install the raw release JAR in `plugins/`:

`SF_SlimeEasy1.0.2.jar`
