# SlimeEasy Legacy 1.0.1

SlimeEasy Legacy `1.0.1` is the first English-first maintenance release of the `wickidcow/SF_SlimeEasy` fork for modern Slimefun Legacy servers.

## Highlights

- Added a complete English (`en_US`) localization covering item names, lore, menus, messages, research, logs, holograms, machines, storage, villagers, and territory features.
- Changed `en_US` to the default language and built-in missing-key fallback.
- Retained the original Simplified Chinese (`zh_CN`) locale as an optional language.
- Translated the default configuration and administrator-facing documentation to English.
- Updated the project README to the Slimefun Legacy maintenance style with compatibility, installation, lineage, and release information.
- Standardized the raw installable release filename as `SF_SlimeEasy1.0.1.jar`.
- Preserved existing SlimeEasy item IDs, recipes, persistent storage keys, territory data, research IDs, and gameplay behavior.
- Includes the upstream fake-player factory refactor from base commit `a0090f0`, used by the Butcher Machine and Auto Clicker.

## Compatibility

| Component | Target |
| --- | --- |
| Minecraft | **26.2** |
| Server | **Paper 26.2+** |
| Java | **25** |
| Primary Slimefun | **Slimefun Legacy** |
| Optional dependency | **DecentHolograms 2.10.1** for Engineer Goggles |
| Default language | **English (`en_US`)** |

SlimeEasy uses Paper's Mojang-mapped NMS/CraftBukkit interfaces and is intentionally Paper-specific.

## Upgrade notes

Stop the server fully before replacing the JAR and back up your Slimefun and SlimeEasy data. Do not use `/reload`, PlugMan, or another hot-unload tool with this addon.

Install the raw release JAR in `plugins/`:

`SF_SlimeEasy1.0.1.jar`
